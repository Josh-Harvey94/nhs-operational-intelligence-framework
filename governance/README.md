# Governance

This folder is a starting point, not a substitute for local assurance.

Minimum workstreams:
- information governance/data protection;
- cyber security;
- access control and DLP;
- clinical safety assessment where applicable;
- records management;
- model/prompt risk;
- operational ownership;
- change control and monitoring;
- benefits and unintended-consequence review.

Recommended artefacts:
- DPIA screening/assessment;
- data-flow map;
- processing-purpose/lawful-basis assessment where personal data is involved;
- access matrix;
- DLP policy review;
- clinical-safety triage and, where applicable, formal DCB0129/DCB0160 artefacts;
- UAT evidence;
- model/prompt test set;
- incident and rollback plan;
- named product/service owner.
