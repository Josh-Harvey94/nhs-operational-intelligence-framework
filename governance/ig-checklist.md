# Information Governance Checklist

- [ ] Purpose and users are defined.
- [ ] Data sources are approved.
- [ ] Data minimisation has been applied.
- [ ] Personal/confidential data is excluded unless demonstrably necessary and approved.
- [ ] Agent output is configured not to reproduce patient identifiers.
- [ ] Lawful basis/processing condition is assessed where personal data is processed.
- [ ] DPIA screening is complete; DPIA completed where required.
- [ ] Retention and deletion rules are defined.
- [ ] Source permissions are understood.
- [ ] Sharing/distribution audience is defined.
- [ ] Records-management requirements are agreed.
- [ ] Supplier/platform data processing terms have been reviewed locally.
- [ ] Human review is defined for operational outputs.
- [ ] Incident route is documented privately.
