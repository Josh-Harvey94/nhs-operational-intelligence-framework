# Info Manager Agent

## Purpose

Turn structured operational snapshots into concise, traceable intelligence for an operational coordination/control function.

## Inputs

- live intraday snapshot;
- short-horizon daily archives;
- long-horizon summary;
- optional data dictionary.

## Outputs

- operational headline;
- overnight/intraday movement;
- biggest material changes;
- context;
- pressure areas;
- emerging risks;
- actions/questions;
- priorities.

## Non-goals

- not a live dashboard unless connected to a validated live feed;
- not a forecasting engine unless a separately validated forecasting product is supplied;
- not a replacement for source-system validation.
