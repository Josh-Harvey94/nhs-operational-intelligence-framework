# HOW TO APPLY THIS UPDATE

1. Keep your GitHub repository PRIVATE for now.
2. In GitHub Desktop, select `nhs-operational-intelligence-framework`.
3. Click `Repository` > `Show in Explorer`.
4. Leave that Explorer window open. You should see README.md, SECURITY.md, agents, docs, sql, etc.
5. Open the downloaded `github-update-pack-v0.1.0.zip`.
6. Select EVERYTHING inside the ZIP.
7. Copy it.
8. Paste it directly into the ROOT of your existing `nhs-operational-intelligence-framework` folder.
9. Windows may ask whether to merge folders and replace existing files. Choose YES / Replace the files in the destination.
10. Go back to GitHub Desktop.
11. You should now see multiple changed files under `Changes`.
12. In Summary type: `Expand SQL, timestamp and Start-of-Play framework`
13. In Description (optional) type: `Adds public-safe SQL patterns, timestamp/cadence controls, synthetic Start-of-Play example and updated architecture.`
14. Click `Commit to main`.
15. Click `Push origin`.
16. Open the repository on GitHub and refresh.
17. Check the Actions tab. The `public-safety-check` should pass.
18. Keep the repository private until you have completed your final visual review.

DO NOT add the original local SQL files or the real operational HTML brief to the public repository.
