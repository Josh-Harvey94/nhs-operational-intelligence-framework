# Phase 2 — Agents

## Info Manager first
Validate with synthetic/historical data before current operations.

Acceptance examples:
- 100% of quantitative claims include retrievable provenance in test set.
- no NULL-to-zero conversion.
- no trend claim from one point.
- no long-horizon answer assembled from disallowed short-horizon files.
- staleness warning works.

## System Grip second
Acceptance examples:
- conflicting sources are surfaced;
- missing owners/deadlines are not guessed;
- PII synthetic tests are redacted;
- organisational boundaries are preserved;
- grip gaps produce useful clarification questions.
