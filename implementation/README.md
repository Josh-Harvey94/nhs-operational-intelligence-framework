# Implementation Plan

## Phase 0 — Discovery and safety boundary
Define intended use, users, decisions, data owners, source authority, local governance and non-goals.

## Phase 1 — Data foundation
Create the structured snapshot contract, data dictionary, cadence, quality controls and synthetic test pack.

## Phase 2 — Info Manager Agent
Build read-only data intelligence. Validate NULL behaviour, source selection, provenance, staleness, comparisons and brief quality.

## Phase 3 — System Grip Agent
Add approved narrative sources. Validate action extraction, grip gaps, discrepancies, redaction and organisational boundaries.

## Phase 4 — Platform governance and ALM
Move components into Power Platform Solutions, use environment variables/connection references, configure DLP, roles, dev/test/prod and change control.

## Phase 5 — Assurance and UAT
Complete IG/security/clinical-safety work as applicable. Conduct structured UAT with operational leads.

## Phase 6 — Controlled go-live
Start read-only/human-reviewed. Monitor errors and near misses. Introduce distribution automation only when justified.

## Phase 7 — Scale and reuse
Add data domains/organisations through configuration, not prompt sprawl. Maintain a shared test suite and changelog.

See the phase files and `go-live-checklist.md`.
