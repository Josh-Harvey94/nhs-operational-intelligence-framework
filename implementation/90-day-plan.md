# Example 90-Day Implementation Plan

## Days 1–15: scope and assurance
- intended use and non-goals;
- source-authority map;
- data owners;
- IG/clinical-safety/cyber triage;
- synthetic test dataset.

## Days 16–35: data product
- live/daily/summary data products;
- quality checks;
- cadence/NULL dictionary;
- staleness alerts.

## Days 36–50: Info Manager
- build prompt/instructions;
- test against curated scenarios;
- iterate with operational leads;
- capture provenance defects.

## Days 51–65: System Grip
- connect only approved narrative sources;
- test actions/grip gaps/discrepancies;
- test redaction and access boundaries.

## Days 66–78: ALM and governance
- Solution packaging;
- environment variables/connection references;
- DLP;
- dev/test/prod;
- assurance artefacts.

## Days 79–90: controlled pilot
- small named user group;
- read-only/human-reviewed;
- daily defect log;
- weekly safety/quality review;
- go/no-go decision for broader deployment.
